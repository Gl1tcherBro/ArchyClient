# ArchyClient

The official ArchyClient for the Adm1nArchy Minecraft server (not affiliated).

Includes:
* Auto GG (Customizable message)
* Auto TPA Accept (Customizable players to accept from)
* Auto Torture (Max of 3 players at a time)
* Auto TPAHERE (Planned for when walking towards a jammer)
* Possibly more to come!
