# ArchyClient

The official ArchyClient for the Adm1nArchy Minecraft server (not affiliated).

Includes:
* Auto GG (Customizable message)
* Auto TPA Accept (Customizable players to accept from)
* Auto Torture (Max of 3 players at a time)
* Settings found in the vanilla options menu


Does not include (yet):
* Auto SkipAdmin (Time that it happens customizable) Planned
* Auto Buy (Keybind based, ONLY WORKS OUTSIDE OF COMBAT) Planned
* Auto TPAHERE (For when walking towards a jammer) Probably Planned
* Possibly more to come!
